## How I work

- Start with a reproducible problem, not a guessed fix.
- Prioritize tests by user impact and release risk.
- Keep changes scoped, reviewable and reversible.
- Treat CI as evidence, not decoration.
- Separate confirmed facts from assumptions and unresolved risks.
- Do not mark work complete until the relevant verification has actually run.
